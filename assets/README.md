# WordPress.org assets

Not shipped in the plugin zip. These live in the `assets/` directory of the
WordPress.org SVN repository and are uploaded by the release workflow.

Required before submission (M8):

| File | Size | Notes |
|---|---|---|
| `icon-128x128.png` | 128×128 | Plugin directory listing |
| `icon-256x256.png` | 256×256 | Retina listing |
| `banner-772x250.png` | 772×250 | Plugin page header |
| `banner-1544x500.png` | 1544×500 | Retina header |
| `screenshot-1.png` | — | Order matches the `== Screenshots ==` list in `readme.txt` |

See https://developer.wordpress.org/plugins/wordpress-org/plugin-assets/
